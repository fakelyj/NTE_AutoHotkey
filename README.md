# NTE_AutoHotkey
这个脚本用于AutoHotkey自动刷取异环店长自供方斯脚本，配置文件是有4k，2k，1k，打开界面后点击f3即可开启自动刷取
This script is used by AutoHotkey to automatically download data from the Yihuan store manager's proprietary software. The configuration file has 4k, 2k, and 1k settings. After opening the interface, press F3 to start automatic downloading.
このスクリプトは、AutoHotkeyを使用してYihuanストアマネージャー専用ソフトウェアからデータを自動的にダウンロードするために使用されます。設定ファイルには、4k、2k、1kの設定があります。インターフェースを開いた後、F3キーを押すと自動ダウンロードが開始されます。
